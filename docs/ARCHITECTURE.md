# 系统架构说明

## 产品范围

主流程是养老机构内对老人开展年度能力检查，覆盖肢体活动、言语沟通、视听能力、心理与认知、日常生活能力五个维度。系统只额外生成机构级脱敏监管摘要，不扩张为跨部门综合监管平台。

## 责任链

```text
摄像头/麦克风/触屏/代录/历史导入
  -> AI或浏览器适配器生成结构化草稿
  -> 检查人员逐字段确认
  -> 确定性规则引擎计算关注等级
  -> 检查或复核人员确认结果
  -> 个人、机构、脱敏监管输出
```

AI 只能转写、播报、整理字段、提示冲突或预选单项观察记录，不能导入或调用 `src/rules/engine.ts`。预选项必须显示来源、置信度和观察依据，允许检查人员确认或改写。规则引擎只读取确认后的结构化数据，不能自行补齐缺项。最终确认必须记录人员、时间和必要说明。

## 版本化等价题库

21个能力检测任务及其0-3档规则保持固定。`YY-01`、`YY-03`、`ST-01`、`ST-02`、`XL-02`只在任务内部抽取等价题面，不增减评分项目。演示版共包含38套变体，并按“档案ID + 检查日期 + 题库版本”稳定选择，同一检查刷新后不会换题。

每份新检查草稿保存题库版本、选择种子、题目ID、实际提示文本、材料和标签快照。复核人员看到的是当时使用的题面，而不是后来更新后的题库内容。语言背景标签只决定交互和质控方式，不参与抽题难度或分档。

当前等价题是竞赛原型内容，尚未完成测量学等值验证。生产试点需要由养老服务专业人员审定题面，进行可理解性、难度、重测和人群分层验证，并建立题库发布与停用流程。

## 可替换适配器

演示版优先使用浏览器能力，生产版可在不改变规则引擎的前提下替换：

- 语音识别：浏览器 `SpeechRecognition`、FunASR、faster-whisper 或 sherpa-onnx。
- 语音播报：浏览器 `speechSynthesis` 或机构内网 TTS。
- 动作辅助：演示版优先使用本机 MediaPipe Pose Full（Lite自动回退），肢体五项统一设计为“老人本人 + 一把稳固椅子”即可完成：椅上坐姿稳定、椅上坐站、坐姿交替抬膝、坐姿双臂抬举、坐姿手指对合。按任务校验必要关键点并进行分位数时序滤波；低质量、遮挡、椅子不稳、疼痛或需要搀扶时转人员现场观察。
- 安全边界：系统只判断人体关键点的动作证据，不自动判断椅子是否稳固，也不鼓励独自站立或行走。坐站项必须有现场监护，其他项保持臀部接触椅面；出现头晕、疼痛或失衡立即停止。
- 视力图卡：从版本化等价字组抽取四张大字逐张显示，语音匹配或人员确认辨认数量后按固定映射预选。
- 大模型：公共演示默认关闭；生产版只允许通过机构控制的后端代理接入，对白名单文本任务输出 `GYZJ-AI-DRAFT-1` JSON 草稿。

语义复核请求只包含任务ID、抽题ID、实际提示、待复核文本、四档说明和语言背景，不包含老人姓名或档案号。响应必须包含0-3档或拒判、置信度、可核对证据、可选白名单追问、安全标记和模型版本。安全标记、低置信度、Schema错误或模型失败全部转人工；前端不保存服务商API密钥，大模型也不能直接写入规则结果。

任何适配器失败、低置信度、噪声、遮挡或老人拒绝音视频时，都允许切换到触屏或护理人员代录。识别置信度与语言背景只能产生质量提醒，不能改变等级。

## 数据与隐私

演示版在浏览器内确定性生成 60 条模拟记录并写入 `localStorage`。除已披露许可的 MediaPipe Pose 模型外，仓库不包含真实姓名、联系方式、老人音视频、医疗健康档案、其他模型权重或 API 密钥。

生产版至少需要：

- 单独告知和知情同意，可撤回并可跳过音视频。
- 最小必要字段、用途限制、保存期限和删除机制。
- 角色权限、加密传输与存储、访问和变更审计。
- 音视频默认不长期保存；确需保存时另行授权并设置期限。
- 监管侧只接收机构计数、完成率和等级分布等脱敏聚合字段。

## 规则策略

每个维度包含 3 或 5 个任务，每项由检查人员记录 0-3 档。规则包括缺项拒判、有效任务不足转人工、单项高关注托底、总体取五维最高档、三个及以上 2 档升级、危机停算、冲突复核、未同意或未确认拒判。规则版本、命中规则、质量提醒和人工说明均随记录保存。

当前分段是竞赛演示规则，不等同于国家标准原文或法定等级。生产试点应由养老服务专业人员依据适用规范校准，并形成受控的规则发布流程。

## 演示与生产部署

| 能力 | 演示版 | 生产版替换项 |
| --- | --- | --- |
| 身份 | 固定演示检查员 | 机构账号、角色和最小权限 |
| 数据 | 浏览器 `localStorage` | 加密数据库、备份恢复、留存策略 |
| 题库 | 5个随机任务、38套等价题、题面快照留痕 | 专业审定、难度校准、重测验证和受控版本发布 |
| ASR/TTS | 浏览器 API | 内网或合规服务，记录组件版本 |
| 姿态 | MediaPipe Full本机推理、Lite回退、单椅安全动作关键点校验、时序去抖和人工纠正 | 椅子/辅具检测、老人样本验证、场景阈值校准或纯人工观察 |
| 视力图卡 | 四张大字逐张显示，记录辨认数量 | 经专业人员校准的字形、距离、亮度和测试流程 |
| 大模型 | 默认关闭，已实现后端端点与JSON契约边界 | 私有或合规模型、第一方代理、最小字段与调用审计 |
| 审计 | 本地确认时间和说明 | 不可抵赖日志、审批与规则版本管理 |
| 监管 | 下载脱敏 JSON 契约 | 经主管方确认的数据标准和接口 |
