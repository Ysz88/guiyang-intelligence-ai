# 桂养智检 AI

面向养老院老人年度能力检查与分级辅助的开源演示站点，兼顾比赛展示、流程试用和后续生产化改造。

在线演示：https://ysz88.github.io/guiyang-intelligence-ai/

本项目聚焦五类年度检查任务：肢体活动、言语沟通、视听能力、心理与认知、日常生活能力。AI只负责采集和结构化，等级由确定性规则引擎计算，并由检查人员最终确认。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建与测试：

```bash
pnpm test
pnpm build
pnpm preview
```

## Cloudflare Pages 部署

项目可作为静态站点部署到 Cloudflare Pages：

```text
构建命令：pnpm build
输出目录：dist
Node.js：20.19+ 或 22.12+
```

仓库的 `public/_headers` 提供基础安全响应头，`public/_redirects` 提供单页应用回退。当前演示数据仍保存在每位访问者自己的浏览器中，不会跨设备同步。

## 演示内容

- 60条自动生成的模拟档案，全部标注“模拟数据，仅用于功能演示”。
- 年度检查工作台和21项可观察任务。
- 肢体检测采用单椅安全动作：椅上坐姿稳定、椅上坐站、坐姿交替抬膝、坐姿双臂抬举、坐姿手指对合；不要求走动或第二把椅子，坐站项由现场人员监护。
- 5个可随机任务、38套等价题，按档案和检查日期稳定抽取，保存题库版本、题目编号与实际题面。
- MediaPipe Pose Full 本机姿态分析（Lite自动回退）、任务关键点校验、时序去抖、骨架叠加、AI预选与人工纠正留痕。
- 等价大字图卡逐张显示、语音匹配或现场确认数量，并按固定规则自动预选。
- 系统语音播报、浏览器语音识别与手工输入降级。
- ASR原文、人工修正文、自愿语言使用背景和确认留痕。
- 确定性规则引擎、缺项拒判、质量提醒、危机线索转人工。
- 个人报告、人工复核、机构汇总和脱敏监管摘要。
- 浏览器本地保存、JSON导出和一键重置演示数据。

## 核心边界

- 辅助检查，非医疗诊断。
- 不产生法定等级；正式结果应由具备相应资质的人员按适用规范确认。
- 语言使用背景和ASR置信度不参与能力评分。
- AI适配器只能预选单项结构化记录，不能调用规则引擎或修改最终结果。
- 可选语义复核只接受第一方后端的 `GYZJ-AI-DRAFT-1` JSON 草稿；API密钥不得写入前端。
- 音视频可跳过，演示站点不保存原始音视频。
- 危机线索、数据冲突和关键缺项进入人工复核。
- 仓库不包含真实老人数据或受限量表全文；仅包含 Apache-2.0 许可的 MediaPipe Pose Full/Lite 模型。

## 当前实现与生产版的区别

当前版本是无需后端即可运行的比赛原型，数据保存在浏览器 `localStorage`。姿态模型在访问者设备内运行，不上传视频；首次分析需要加载约18MB的本地静态模型与运行时文件。等价题库用于减少固定题记忆，不代表已经完成测量学等值验证。正式部署仍需进行题目难度校准、场景标注、阈值校准和老人群体分层验证，并替换为服务端身份认证、分角色授权、加密数据库、备份恢复、不可抵赖审计日志以及经过审批的数据交换接口。ASR、姿态识别和大模型均设计为可替换适配器，不影响确定性规则核心。
